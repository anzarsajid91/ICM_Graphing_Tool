# Synthetic reference fixtures

Every dataset and report here is generated from scratch by `scripts/generate_synthetic_references.py`. No uploaded source file is read, shifted, scaled or pseudonymised. The seed describes only the fictional examples.

The FDV/R files and association workbook share a new network, identifiers, pipe sizes and timestamps. Flow/depth/velocity follow circular-pipe area relationships; upstream traces form an acyclic network. The fourth gauge is deliberately unassociated. CSV/HYD/ZIP formats retain their parser contracts. Long gaps and unresolved rainfall units remain deliberate test cases. Detriment exports include fresh date-in-numeric-field and date-only-boundary audit cases.

The original screenshots were removed because pixels cannot be reliably anonymised. Five freshly generated HTML reports preserve plot/table/threshold presentation examples. Expected statistics are calculated from the generated raw values independently of application parsers and engines.

These files are test examples only. They are excluded from the production Pages artifact. The application does not fetch them. Replacing current files does not remove old Git commits, branches, forks or cached artifacts.
