## Proposed defaults for engineering corrections

### A-01 · Survey volume balance

Use the documented weekly window clipped to the requested analysis bounds. Let requested seconds be the duration of that window, eligible seconds be that duration after the union of relevant reviewed exclusions, and common seconds be the duration in which the downstream and every mapped required upstream monitor all have valid bounded support after the same union mask. Integrate each station's piecewise-linear record on exactly that common set using the existing trapezoid method. Preserve original individual support, input units and exclusion provenance for audit. Measure unexplained missing time once at the path level. Use the current RAG thresholds on the matched volume ratio. Require positive common duration and a positive upstream total.

**Default RAG** — An intentionally excluded period is outside the eligible window for every station. When common equals eligible and both volumes can be assessed, apply Green/Amber/Red to that eligible support and show the phrase **Assessed on retained support** with common/requested seconds if any reviewed time was excluded. Preserve the current clipping of short analysis-boundary weeks and explicitly identify those cases. When common is positive but below eligible due to missing/incompatible support, show Grey with the supported subset and any exploratory ratio clearly qualified. If zero eligible/common time remains, withhold ratio and use Grey. A missing tributary or non-positive upstream signed volume keeps the existing Grey/withheld outcome. Where archived compatibility is needed, retain the legacy FSAT computation as explicitly labelled independent legacy evidence.

For either one-sided 120 s exclusion in the synthetic 240 s fixture, both stations must be integrated over the other 120 s. The result is 12/12 m³, ratio 1.000, Green **on retained support**. **Default verification decision gate** — `Acceptable` requires current evidence on a confirmed comparable basis, positive common duration covering the full requested window, and at least two distinct paired timestamps associated with that common support.
