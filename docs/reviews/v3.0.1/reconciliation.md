## Engineering judgement and residual decisions

- **Coverage policy.** Neither reviewer treats a one-sided exclusion as
  project approval for a whole-week decision. A identified the exact
  established shared-exclusion contract supporting Green on complete
  eligible retained evidence. B requires visible common and requested time
  and a documented project criterion. The implementation uses both bases,
  leaves individual exclusions attributable, and withholds formal decisions
  where their actual scope is unsupported. Project-specific minimum coverage
  and permitted exclusions remain with the engineering authority.
- **Verification decision floor.** Full requested joint support, current
  comparable evidence and two distinct qualifying pairs are the operational
  eligibility floor for the default uncaveated decision. This preserves
  stronger project requirements. Caveated decisions need a recorded eligible
  basis and reason. Independent event and matrix criteria remain separate.
- **Spill policy and direction.** Extend incomplete-evidence semantics without
  changing complete-case policy. Map source-direction records using the
  demonstrated import vocabulary. Keep broader ICM export variants and any
  new override/provisional authoring workflow for independently validated
  scope. Existing documented manual overrides require traceable review.
- **Strategic design.** The verified fixture has the same number of drawn
  marks in both schematic modes. Group and destination clarity, named
  landmarks and report interpretation are measurable outcomes. Minimum
  reduction by count does not substitute for those outcomes.
- **Assurance mechanism.** Release-evidence ownership and the authorised
  post-deployment publication mechanism remain external dependencies for
  DE-14. Preserve the existing truthful evidence gap when they are absent.
  The review supports software decisions within the observed scope.
